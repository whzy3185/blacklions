# blacklions

2026 高教社杯全国大学生数学建模竞赛 B 题项目：无线电干扰源的快速自动定位与清除。

当前仓库包含：

- `docs/B题_高上限建模与算法总方案.md`：数学建模、严格几何推导、在线策略与算法总方案（当前主版本）。
- `scripts/B题_几何验证.py`：关键几何结论的独立数值验证脚本。
- `results/B题_几何验证_运行结果.txt`：验证脚本当前运行结果。
- `archive/B题_高上限建模与算法总方案_v1备份.md`：上一版方案备份。
- `source/`：赛题与附件原始文件。

后续将在本仓库继续迭代模拟器程序、演练数据、参数调优结果与论文稿。
