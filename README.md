# blacklions

2026 高教社杯全国大学生数学建模竞赛 B 题项目：**无线电干扰源的快速自动定位与清除**。

当前 `main` 分支已经同步本轮建模与验证成果：

- `scripts/B题_几何验证.py`：关键几何结论的独立数值验证脚本；
- `results/B题_几何验证_运行结果.txt`：当前验证结果；
- `docs/_payload/`：当前主建模文档 `B题_高上限建模与算法总方案.md` 的无损压缩分段、校验清单；
- `scripts/restore_model_doc.py`：一键恢复主建模 Markdown，并自动校验 SHA-256。

## 恢复主建模文档

克隆仓库后运行：

```bash
python scripts/restore_model_doc.py
```

脚本会生成：

```text
docs/B题_高上限建模与算法总方案.md
```

当前主文档 SHA-256：

```text
864789bb1d616e3d50507b83854554b789e19d86d5518a7ffcb5fe4f961a8589
```

详细载荷尺寸和逐段哈希见 `docs/_payload/MANIFEST.md`。
