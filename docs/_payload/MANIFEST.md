# 主建模文档 Payload 清单

该目录保存当前主建模文档 `B题_高上限建模与算法总方案.md` 的**无损可校验压缩载荷**。由于上传接口采用 UTF-8 文本写入，主文档先使用确定性 gzip（`mtime=0`）压缩，再进行 Base64 编码并拆成 3 段提交。

克隆仓库后执行：

```bash
python scripts/restore_model_doc.py
```

即可在 `docs/B题_高上限建模与算法总方案.md` 恢复出与当前本地版本逐字节一致的 Markdown，并自动校验 SHA-256。
